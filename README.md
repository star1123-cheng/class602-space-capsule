# 國小五升六班親會：「航向六年級的時空補給站」操作說明手冊

本專案為國小五升六班親會量身打造之互動式無重力漂浮信箱（Antigravity 飄浮信箱）。專門針對**家長手機直式操作**全面最佳化，前端具備 Canvas 星空背景、微重力漂浮粒子物理碰撞、毛玻璃現代美學，並支援「家長留言發射」與「學生拆信回覆」雙向互動機制。

---

## 📋 班級成員與太空膠囊配置

系統內建全班 16 位同學與導師「張祐誠」之專屬時空膠囊，家長與學生在手機上可直接點選座號進行互動。

> [!NOTE]
> 系統初始狀態為乾淨的 17 顆微光太空膠囊待裝填（無任何預設留言）。所有留言與回覆將即時同步至雲端試算表安全保存。

---

## 📱 手機介面與核心功能特色

### 1. 畫面正中央核心儀表板（Mobile Center Hub）
- **視覺集中**：所有核心操作按鈕皆放置在畫面正中央，完美適配手機單手拇指操作區（不再散落四角）。
- **即時裝填進度儀表**：清晰呈現「已裝填 X / 17」進度條，班親會現場成果一目了然。
- **全景星空探索切換**：點擊右上角「探索星空」，可一鍵淡出主面板，讓手機全螢幕沉浸式漫遊於漂浮膠囊中；點擊右下角按鈕隨時切回選單。

### 2. 模式一：家長留言端（親師會現場使用）
- 點擊中央大按鈕**「✍️ 寫下給孩子的航行補給」**，由底部升起專屬手機抽屜表單。
- 點開選單直接挑選「孩子座號」（例如：`01 號`）或「導師」。
- **靈感金句**：提供 4 組五升六專屬引導標籤，點擊一鍵填寫感動文字。
- **家長署名**：支援快捷鍵（媽媽、爸爸）或自訂輸入。
- **封存發射**：送出後立即噴發彩帶紙花，該成員的飄浮膠囊瞬間由「待裝填」點亮為耀眼的「已封存 ✉️」藍色光芒！

### 3. 模式二：學生掃 QR code 開信（`student.html`）
- 每位學生有專屬 QR code，平板掃描後只會看到寫給自己的信，可以逐則回覆與修改。
- 解鎖時間前只顯示倒數與信件數量；解鎖時間由後端判斷，改前端也讀不到內容。
- 看完按「關閉信箱」，下一位同學就回不到上一位的信件。
- 可自行存成回憶集 PDF，或列印 A4 手寫信紙。

### 4. 導師後台（`teacher.html`）
- 輸入導師密碼後，可列印 QR code 卡片、列印 A4 手寫信紙（上半留言、下半手寫）、匯出回憶集（在列印視窗選「另存為 PDF」）。
- 卡片遺失時按「重設」，舊 QR code 立刻失效。
- A4 手寫信紙只放家長的信；同學的信只收進回憶集。

### 5. 學生互寫（`classmates/`）
- 學生掃自己的 QR code 後，在學生頁按「寫信給同學」進入，不用另外印卡片。
- 署名固定為寄件人座號（例如「07 號同學」），不能自填；每位同學限寫一封，寄出後可修改。
- 同學的信和家人的信一起在解鎖時間打開，不算進首頁的裝填統計。
- 沒有事前審核：發現不適當的內容，請在解鎖前到試算表直接刪除那一列（「寄件類型」欄為「同學」，「寄件座號」欄是寫信的人）。

## ☁️ 部署步驟（順序不可對調）

1. 把 `Code.gs` 內容貼到 Apps Script 編輯器並儲存。
2. 到「專案設定 → 指令碼屬性」新增 `TEACHER_KEY`，值由導師自行設定。密碼不要寫進程式或傳給別人。
3. 執行一次 `setupSheet`，補上「留言編號」欄位。
4. 到「部署 → 管理部署作業」編輯現有部署，版本選「新版本」，網址就不會改變。
5. 再把 `index.html`、`student.html`、`teacher.html`、`capsule-shared.js`、`capsule-print.css` 推上 GitHub Pages。

> [!WARNING]
> 這個 Web App 是「以我的身分執行 + 任何人可存取」，家長才能免登入留言，但知道網址的人都能呼叫它。因此留言內容必須憑學生代碼或導師密碼才能讀取，這層檢查不可移除。

解鎖時間只要改 `Code.gs` 開頭的 `UNLOCK_AT`，再發布新版本。

## 🗂️ 資料保存

留言存放在 Google 試算表，內容包含家長與孩子的私人對話。建議學生畢業、回憶集發還後，清除試算表內容並停用部署。
