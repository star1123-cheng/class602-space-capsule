# 國小五升六班親會：「航向六年級的時空補給站」操作說明手冊

本專案為國小五升六班親會量身打造之互動式無重力漂浮信箱（Antigravity 飄浮信箱）。專門針對**家長手機直式操作**全面最佳化，前端具備 Canvas 星空背景、微重力漂浮粒子物理碰撞、毛玻璃現代美學，並支援「家長留言發射」與「學生拆信回覆」雙向互動機制。

---

## 📋 班級成員與太空膠囊配置

系統內建全班 16 位同學與導師「張祐誠」之專屬時空膠囊，家長與學生在手機上可直接點選座號進行互動。

> [!NOTE]
> 系統初始狀態為乾淨的 17 顆微光太空膠囊待裝填（無任何預設留言）。所有留言與回覆將即時同步至雲端試算表安全保存。

---

## 📱 手機介面與核心功能特色

### 1. 畫面正中央核心儀表板（Mobile Center Hub）
- **視覺集中**：所有核心操作按鈕皆放置在畫面正中央，完美適配手機單手拇指操作區（不再散落四角）。
- **即時裝填進度儀表**：清晰呈現「已裝填 X / 17」進度條，班親會現場成果一目了然。
- **全景星空探索切換**：點擊右上角「探索星空」，可一鍵淡出主面板，讓手機全螢幕沉浸式漫遊於漂浮膠囊中；點擊右下角按鈕隨時切回選單。

### 2. 模式一：家長留言端（親師會現場使用）
- 點擊中央大按鈕**「✍️ 寫下給孩子的航行補給」**，由底部升起專屬手機抽屜表單。
- 點開選單直接挑選「孩子座號」（例如：`01 號`）或「導師」。
- **靈感金句**：提供 4 組五升六專屬引導標籤，點擊一鍵填寫感動文字。
- **家長署名**：支援快捷鍵（媽媽、爸爸）或自訂輸入。
- **封存發射**：送出後立即噴發彩帶紙花，該成員的飄浮膠囊瞬間由「待裝填」點亮為耀眼的「已封存 ✉️」藍色光芒！

### 3. 模式二：拆信展讀端（晨光時間查閱與多則信件）
- 點擊中央**「🚀 學生晨光登入解鎖」**（或直接在星空中點擊發光的專屬膠囊）。
- 膠囊伴隨光暈飛移至中央，展開為典雅的「時空補給信紙」。若收到多位家長留言，將依序展開多則信件清單。
- **雙向愛心回信**：信紙下方提供回覆框與金句，送出後蓋上「已親啟回信」印章，膠囊轉為溫暖金色光芒。

## 🚀 快速展示方式（目前本機即開即用，免佈署）

1. 在檔案總管中，對著 [`index.html`](file:///g:/我的雲端硬碟/antigravity/教學/班務/班親會/index.html) 點擊兩下或拖入 Chrome / Edge 瀏覽器開啟。
2. 亦可按 `F12` 開啟開發者工具並切換至「手機模擬模式 (iPhone / Pixel)」，體驗手機直式操作之流暢感。
3. 若現場需要重設紀錄重新展示，點擊右上角「⚙️ 設定」->「清空留言紀錄」即可一秒還原至全新狀態。

## ☁️ 未來串接 Google 試算表（Google Sheets）步驟

未來正式啟用時若需將家長留言與學生回信同步至 Google 試算表：
1. 建立空白 Google 試算表，進入「擴充功能 -> Apps Script」。
2. 將 [`Code.gs`](file:///g:/我的雲端硬碟/antigravity/教學/班務/班親會/Code.gs) 與 [`appsscript.json`](file:///g:/我的雲端硬碟/antigravity/教學/班務/班親會/appsscript.json) 複製貼入。
3. 執行一次 `setupSheet`。
4. 部署為 Web 應用程式（Execute as: Me / Access: Anyone），取得 Web App URL。
5. 在網頁右上角「⚙️ 設定」中貼上 URL 即可無痛切換為雲端模式！
